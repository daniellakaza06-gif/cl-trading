# Trade Intelligence

Streamlit analytics for your weekly trading workbook.

Pages: Command Center · Performance · Day Explorer · Goals · Risk Lab · Coin Intelligence · Projection Lab · Trade Ledger · Data Quality

## Deploy
1. Upload to one GitHub repo: `streamlit_app.py`, `trading_data.xlsx`, `requirements.txt`, `.streamlit/config.toml`.
2. share.streamlit.io → New app → pick the repo → main file `streamlit_app.py` → Deploy.

## Adding a new week
Add the sheet to `trading_data.xlsx`, commit, and the app updates. Or drop a workbook in the sidebar uploader to preview.
